Sound effects for the tour. Drop 16-bit PCM WAV files here named exactly:

  drive_engage.wav  - scale drive winding up (departure, the three-stage drop)
  shrink.wav        - one power-of-ten scale step
  heartbeat.wav     - a single lub-dub (the Heart)
  klaxon.wav        - immune alert (the Sentinel)
  alarm.wav         - hull / camouflage warning
  impact_soft.wav   - a pseudopod or cell grazing the hull
  chime.wav         - arrival / re-expansion complete
  spark.wav         - an action potential firing past the ship
  squelch.wav       - membrane / vesicle squeeze

These are OPTIONAL. If a file is missing, the app plays a built-in synth cue
from BodyAudioEngine instead, so the ride still has a beat there.

Royalty-free sources: generate at https://fish.audio/app/sound-effects/ or
download from https://freesound.org (CC0).
