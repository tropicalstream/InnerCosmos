# Plates — the pictures shown in Chapter III

Two Chinese artworks of Norman Bethune (白求恩), each displayed inside the passage at the
stop whose narration it belongs to:

| file | what it is | shown at |
| --- | --- | --- |
| `yanan.jpg` | oil painting of Mao Zedong and Bethune in conversation, Yan'an, 1938 | 4. The Front |
| `portrait.jpg` | scroll portrait inscribed "伟大的国际主义战士白求恩同志" | 10. The Memory |

**Provenance:** these were supplied for this project, not created for it. They are
mid‑twentieth‑century Chinese artworks whose copyright status has not been cleared. That is
fine for a personal, non‑commercial build running on one pair of glasses; before this
repository or an APK is distributed more widely, they should be credited to their artists,
replaced with public‑domain images, or removed (delete this folder and the chapter simply
runs without them).
